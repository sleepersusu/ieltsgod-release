# 雅思練習室 IELTS Practice Room

聽力精聽、閱讀、寫作 AI 批改的雅思練習程式。這裡只放安裝檔。

## 下載安裝

到右邊的 **[Releases](../../releases/latest)** 下載最新版：

| 電腦 | 下載這個 | 怎麼裝 |
|---|---|---|
| Windows | `IELTSPracticeRoom-Setup.exe` | 點兩下 → 下一步 → 完成。如果出現藍色的「Windows 已保護您的電腦」，按「其他資訊 → 仍要執行」 |
| Mac | `IELTSPracticeRoom-mac.dmg` | 打開後把「雅思練習室」拖進「應用程式」。第一次打開請在「應用程式」裡對它按右鍵 → 打開 |

裝好之後有新版會自動通知、自動更新，不用再來這裡下載。

## 第一次打開

- 會問要不要用 Google 雲端硬碟同步（要先裝 [Google Drive 電腦版](https://www.google.com/drive/download/)），換電腦也能接著練；只用一台電腦選「全新開始」就好。
- AI 功能（寫作批改、出題、閱讀解析）要用你自己的 Claude、Gemini 或 ChatGPT 帳號，練習室裡會一步一步帶你登入。

## 練習紀錄存在哪裡

- 你的電腦：`使用者資料夾/雅思練習室/題庫`（更新、重裝、解除安裝都不會刪掉）
- 有開雲端同步的話，另外在 Google 雲端硬碟的「雅思練習室備份」
